---

# Objetivo do Programa 📝

Esse projeto tem como objetivo apresentar simular o monitoramento do reservatório com dados diretos do terminal, apresentando cada nível com uma mensagem de alerta colorida de acordo com as condições.

**Condições:**


| Nível do Reservatório | Situação / Alerta | Cor Sugerida |
|---|---|---|
| Nível 1 | Muito baixo (crítico) | ![Vermelho](https://img.shields.io/badge/Vermelho-ff0000?style=flat-square&logoColor=white) |
| Nível 2 | Baixo | ![Amarelo](https://img.shields.io/badge/Amarelo-ffff00?style=flat-square&logoColor=black) |
| Nível 3 | Médio | ![Verde](https://img.shields.io/badge/Verde-00ff00?style=flat-square&logoColor=black) |
| Nível 4 | Alto | ![Ciano](https://img.shields.io/badge/Ciano-00ffff?style=flat-square&logoColor=black) |
| Nível 5 | Muito alto (alerta) | ![Azul](https://img.shields.io/badge/Azul-0000ff?style=flat-square&logoColor=white) |

---

**Objetivo da atividade:**
* Publicação do código-fonte através do Git e GitHub

# Como Utilizar? 👨‍💻

**Pré-requisitos**

→ Ter o Python 3 instalado no computador.

Para verificar se o Python está instalado, execute no terminal:

```bash
python --version
```
---

→ Instale a biblioteca necessária (colorama):
```bash
pip install colorama
```

---

**Executando o projeto**

→ Clone este repositório:

```bash
git clone https://github.com/misantos13/CamilaFerreiraSantos_Ag11_DSI_Recup.git
```

→ Entre na pasta do projeto

→ Execute o programa `app.py`
